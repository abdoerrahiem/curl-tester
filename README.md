# cURL & API Tester

A modern, fast, and lightweight web-based API testing client and raw cURL runner built with React, Vite, Tailwind CSS, and Express.js proxy.

Live: [https://curl.abdurcodes.com](https://curl.abdurcodes.com)

## Features
- **cURL Runner Tab**: Run raw multiline cURL commands with intelligent dirty log sanitization (cleans Flutter/Dio, Android Logcat, OkHttp, and terminal box-drawing prefixes).
- **Format & Clean**: One-click formatting of messy cURL logs into clean, readable syntax.
- **API Tester Tab**: Interactive visual request builder (Method, URL, Headers, JSON payload, live cURL preview, code export).
- **Code Generation**: Export requests to JavaScript (Fetch), Python (Requests), and Go.
- **SSRF Protection**: Proxy backend blocks localhost and private IPv4/IPv6 ranges.
- **Modern Minimalist UI**: Flat zinc design with dark & light theme toggle.
